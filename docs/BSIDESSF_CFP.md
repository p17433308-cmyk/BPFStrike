# BSidesSF 2027 CFP — BPFStrike

**Session Type:** Presentation, 45min
**Track:** Infrastructure Security
**Tool:** https://github.com/p17433308-cmyk/BPFStrike (open-source)

## Session Title (≤60)
BPFStrike: An eBPF Offensive Security Framework

## Session Abstract (≤300)
eBPF runs attacker code in your kernel — and the very tools defenders trust (Falco, Tetragon, Tracee) rely on it. BPFStrike generates real eBPF bytecode for syscall hooking, process/file hiding, credential harvesting, container escape, and evading those tools, plus forensics to catch malicious BPF.

## Session Content

### Thesis / Takeaway
eBPF lets code run in the kernel with deep visibility and control — which is why both attackers and the defensive tools watching for them (Falco, Tetragon, Tracee) live there. This talk shows the offensive side concretely, with real generated eBPF bytecode, and the forensic side that catches it. Attendees leave able to reason about eBPF as an attack surface and to detect malicious BPF on their own hosts.

### Intended Audience
Detection engineers, cloud/Linux platform and container-security teams, incident responders, and offensive researchers. Comfort with Linux internals helps; no prior eBPF development needed.

### Outline (45 minutes)
1. (0-4) Cold open: a process that does not appear in ps, hidden by a BPF program — then we find it. The hook.
2. (4-11) eBPF primer for security: programs, maps, the verifier, and why so much security tooling is built on it.
3. (11-20) Offensive BPF with real generated bytecode (not simulation): syscall hooking, process and file hiding, credential harvesting, XDP interception, container escape, keylogging, and BPF self-hiding.
4. (20-28) Evading the watchers: bypassing Falco/Tetragon/Tracee via io_uring and map corruption — why eBPF-based detection can be blinded.
5. (28-34) Verifier-bypass research: CVE-based bypass patterns and complexity bombs, grounded in well-documented eBPF verifier/kernel CVEs.
6. (34-40) Turning it around: forensic detection of malicious BPF by bytecode pattern analysis mapped to MITRE ATT&CK; reconnaissance of loaded programs and maps.
7. (40-44) Takeaways: what to monitor, the released framework, and ELF output usable with bpftool/libbpf.
8. (44-45) Q&A.

### Novelty
A comprehensive, open-source offensive eBPF framework that emits real, loadable bytecode across eight attack primitives plus evasion and forensics — to our knowledge the most complete open offensive-eBPF toolkit, versus the scattered single-CVE PoCs that exist today. 140 automated tests; eight documented eBPF verifier/kernel CVEs referenced.

### Scope / ethics
For authorized testing, detection engineering, and research. Offensive techniques are demonstrated on the presenter's own hosts; the lasting value for defenders is the detection and ATT&CK-mapped forensics.
